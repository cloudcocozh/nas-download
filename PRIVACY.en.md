# Privacy Notice

[中文](PRIVACY.md) | English

Nas Download stores accounts, downloader and site configurations, sessions, and operation records on your own NAS. Downloader passwords, site API keys, sign-in cookies, request headers, and request bodies are stored encrypted. Sign-in credentials are not shown again on the edit screen or written to runtime logs. Android login tokens are protected by the system Keystore. To prevent duplicate submissions when an outcome is unknown, the web interface stores operation IDs and non-sensitive settings in the current browser. It does not store site keys, sign-in cookies, request headers, or request bodies there.

This version contains no advertising, telemetry, or developer cloud account, and does not upload configurations to developer services. Installation requires connections to upstream image and software dependency providers. Search and download operations contact sites, downloaders, and trackers according to your configuration. You control remote access and backups.

Deleting a site or downloader configuration removes only the connection. When deleting a download task, you must explicitly choose whether to delete its files. You can revoke login access in device settings. Uninstalling the phone app does not delete NAS files. Before removing the NAS service, follow the [installation instructions](docs/INSTALL_RELEASE_EN.md) to back up or handle your data.
