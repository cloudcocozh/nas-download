    Android versionCode 6。默认内置下载引擎，管理服务和 qBittorrent 5.2.4 在同一个产品容器运行；高级模式继续支持已有下载器。手机安装默认内置模式，端口校验与 Linux 安装器一致（1024–65534），上传显示实际百分比并为大安装包延长等待时间。

    完整离线包包含已构建镜像，轻量源码包可在 NAS 构建。首次需 Linux NAS、SSH、Docker Compose 和容器权限；本版首先验证 x86_64，ARM 尚未测试。应用签名继续沿用原发布签名，升级保留用户凭据。

    任务、路径、引擎恢复、升级回滚及真实下载验收由当前验收记录报告；此说明不将计划或模拟测试作为实际设备通过。作为 1.3.0 测试版发布于本仓库 Releases。

    本版已在 x86_64 Linux NAS 隔离环境验证单容器实际下载、暂停继续、删除补种、引擎故障恢复、重启以及强制回滚。正常双容器迁移已验证：旧引擎停止，原会话、任务哈希、路径及文件 SHA256 保留。具体取证见最终验收报告。完整包内含已构建镜像；公开发行定位为测试版，没有完成长期运行观察，也不宣称所有 NAS、ARM 或所有手机均兼容。手机 SSH 协议与签名升级另用隔离模拟器核对。

    本文件可离线阅读，无外部字体、脚本或统计请求。示例地址和路径须替换成自己的值。打印前会显示全部章节。
