    安装、升级与发布核对（1.3.0）

    简体中文 | English

    默认内置下载，一个产品容器；高级 existing 模式接入已有下载器。手机 SSH 安装仍要求 Linux NAS、SSH、Docker Compose 及账户的 Docker 权限，先核对 SHA256 主机指纹。当前首先验证 x86_64 Linux；ARM 尚未测试，不承诺通用 NAS 兼容。

    解压安装包，在私有临时目录执行 sh install.sh --dir /数据盘/docker/nas-download --port 7120 --mode bundled，可用 --downloads /数据盘/downloads 指定目录。服务端口范围 1024–65534，内置模式下一端口供 BT TCP/UDP 使用，内部下载管理端口不公开。existing 不自动搬迁既有任务。

    完整安装包根目录含 nas-download-image.tar.gz，安装器通过 Docker load 导入，无需在 NAS 构建。轻量源码包不含镜像，首次构建须能取得基础镜像及依赖。生成完整包：python deploy/package.py --image /路径/nas-download-image.tar.gz；不加参数生成轻量包。Android 内置相同安装包，必须在镜像和服务代码冻结后重建 APK。

    手机上传到本次创建的私有 /tmp 目录，显示真实上传百分比；允许大包上传和镜像导入时间。成功只清理本次私有暂存目录；失败保留暂存用于排障。安装成功协议包含 NAS_DOWNLOAD_READY、NAS_DOWNLOAD_SETUP_CODE 和 NAS_DOWNLOAD_PROJECT，初始化码须私下保存。网页可访问不代表下载完成，内置模式安装还需验证引擎健康。

    目录由当前账户写入检查；服务使用指定 UID/GID，不递归替其他目录改权限。升级复用同一目录与项目，保留凭据、密钥、下载路径和任务。切换前备份匹配的数据库、引擎恢复文件及部署配置；失败时停止对应实例再恢复匹配快照，不能将旧数据库覆盖运行中的新记录。下载文件另外保存；移除程序默认保留文件。

    发布核对：后端、Android、镜像、内置安装包都为 1.3.0，Android code 6。保持既有发布签名。检查安装包无私人地址、账号、令牌、数据库和密钥，保留第三方材料。记录各制品 SHA256、签名、实际测试环境及未验证项。公开验收摘要见 验收记录；源码测试不等于手机 SSH 安装或所有设备均通过。

    本版已在 x86_64 Linux NAS 隔离环境验证单容器实际下载、暂停继续、删除补种、引擎故障恢复、重启以及强制回滚。正常双容器迁移已验证：旧引擎停止，原会话、任务哈希、路径及文件 SHA256 保留。具体取证见最终验收报告。完整包内含已构建镜像；公开发行定位为测试版，没有完成长期运行观察，也不宣称所有 NAS、ARM 或所有手机均兼容。手机 SSH 协议与签名升级另用隔离模拟器核对。

    本文件可离线阅读，无外部字体、脚本或统计请求。示例地址和路径须替换成自己的值。打印前会显示全部章节。
