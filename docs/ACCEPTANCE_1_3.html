NASDownload 1.3.0 验收记录

日期：2026-10-07。独立产品包名 com.nasdownload.app，版本码 6。

已完成

  • 默认单容器集成 qBittorrent 5.2.4；首次部署不需要另装、另配 qB。仍支持高级设置接入外部下载器。
  • 内置下载器接口仅监听容器回环地址并保留认证；服务端口和下载连接端口可配置。安装包包含 x86_64 离线 Docker 镜像，减少 NAS 首装拉取依赖。
  • 独立安装目录、安装互斥锁、路径/端口检查、升级期间维护门禁；先准备镜像，再停止所属实例并备份匹配的配置与状态。
  • 引擎故障有限重启、退出保存状态、停止期间禁止新业务变更；升级失败自动恢复旧镜像及对应状态，下载文件不倒退覆盖。
  • 保留无人值守的归属校验、观察期、删除前核验和补种记录；测试未连接用户 PT 账号或改动线上保种策略。

现有系统保护与收尾

全部测试在专用目录和独立端口执行。原三合一及其下载器、M-Team、NAStool、Studio、OpenClaw 等七个服务逐一核对，容器 ID、启动时间不变，仍运行；原独立产品预览维持停止。

本轮创建的三个测试容器、两个空测试网络已移除。隔离测试记录及回滚副本保留备查，没有删除用户下载或媒体文件，也未进行全局镜像清理。

支持范围

本次验证环境是 Linux x86_64 NAS、Docker Compose、具有对应 Docker 权限的 SSH 账号，以及 Android 模拟器。ARM NAS 不在当前离线镜像支持范围。未完成多日 PT 持续运行、所有 NAS/手机型号兼容性或公网入站验证；容器减少本身不承诺提高上传速度。
